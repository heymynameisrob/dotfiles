# Golden rules

- ALWAYS ALWAYS communicate in ASD-STE100 / Simplified Technical English. Limit use of jargon and AI slop.
- Always write functions with `function name()...` never arrow functions
- Always use JSDoc style comments, never //
- Always remove \*.log files created from lint or typecheck after you're done
- Don't use sub-agents, unless instructed by the user
- Dont run typecheck, lint, or tests unless instructed by the user
- When proposing a solution, suggest something you may not have initially thought of

# Commit messages

Follow these rules when writing commit messages:

- Keep it to one line
- Limit the line to 75 characters
- Capitalize the subject line
- Do not end the subject line with a period
- Use the imperative mood in the subject line
- Use the message to explain what and why vs. how
